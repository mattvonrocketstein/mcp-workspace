## About 

JSON files in this directory are mcpjungle tool groups, loaded automatically when `tools` starts.

See the [upstream docs](https://github.com/mcpjungle/MCPJungle#tool-groups)

## Examples

```json 
{
    "name": "my-group",
    "description": "Tool Group Test",
    "included_tools": [
        "filesystem__read_file"
    ]
}
```
